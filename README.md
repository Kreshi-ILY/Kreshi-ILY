### ⚔️ Featured project

<p align="center">
  <a href="https://github.com/LastArk123/DeadlyModAnalyzer">
    <img src="https://github-readme-stats.vercel.app/api/pin/?username=LastArk123&repo=DeadlyModAnalyzer&theme=radical&hide_border=true&bg_color=0d0d0d&title_color=e0245e&icon_color=e0245e&text_color=c9d1d9" alt="DeadlyModAnalyzer" />
  </a>

**[DeadlyModAnalyzer](https://github.com/LastArk123/DeadlyModAnalyzer)** checks a Minecraft `mods` folder during a screenshare:

- 🔍 Verifies every jar against **Modrinth** by SHA-1 hash
- 🧬 Scans for known **cheat-client signatures**
- 🚩 Flags sneaky launch args like `-Dfabric.addMods`
- 🌐 Shows where each file was **downloaded from** (Modrinth, Discord, MEGA…)
